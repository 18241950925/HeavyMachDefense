# Heavy MACH: Defense — Windows 中文高清版

双击本目录的 `HeavyMachDefense.exe` 启动。全屏启动可以双击 `Fullscreen.cmd`。游玩不需要安装 Python、Java 或 Rust。

本版为 `1.0.3-zh4`，同步 Android 中文增强版的汉化、简体中文字体、高清文字、机甲及技能图标修复、购买按钮恢复战斗和首次基地升级加载优化。覆盖更新时先关闭游戏，再替换旧目录中的同名文件，保留 `runtime/touchHLE_sandbox` 存档文件夹；发布 ZIP 不包含玩家存档。

启动器会根据屏幕尺寸自动提高内部渲染分辨率。1080p 屏幕通常使用 640×960 的大窗口，或在全屏时以 960×1440 渲染后缩放到屏幕；同时启用 Windows 高 DPI 支持，减少系统缩放导致的模糊。全屏仍保持原版竖屏比例。

需要手动调整时，用记事本打开 `Display.ini`：`Scale=0` 为自动，`Scale=2` 为 640×960，`Scale=3` 为 960×1440，`Scale=4` 为 1280×1920，最高为 6 倍。`Fullscreen=1` 可让双击 EXE 默认全屏。修改后重新启动游戏即可。若出现卡顿，可降低倍数；`Fullscreen-Low.cmd` 可直接使用原始 320×480 渲染。

菜单、升级属性和帮助文字会以更高分辨率重新绘制，包含灰度文字贴图路径；随包的简体中文字体修复方框和缺字，并调整小字排版。提高渲染分辨率能减少放大模糊，原版游戏美术的细节仍受素材分辨率限制。

这是工作区内 iOS 1.0.3 安装包的原版程序，通过修改后的 touchHLE 在 Windows 上运行。游戏图片、音乐、关卡和战斗逻辑来自原安装包。

使用鼠标左键代替触屏点击，按住左键拖动代替滑动。标题画面点击进入，选择“新建”建立存档，在关卡界面选择第 1 关并点击右下角“确定”。第一次进入会显示帮助，点击底部“关闭帮助”进入战场。新存档自动使用名字 `Player`。

游戏的能量用于生产机甲，`Cr` 表示金币，用于购买、研究和升级。选择生产单位、等待完成，然后在战场上指定目标位置。摧毁敌方基地过关；“菜单”“基地升级”等按钮沿用原版位置。底部前两个按钮分别用于出兵和特殊攻击，第三个是原版金币内购入口，本版会取消购买并继续战斗，不增加或扣除金币。

存档保存在 `runtime/touchHLE_sandbox` 内。备份进度时复制这个文件夹；关闭窗口前请点击“菜单” → “保存并退出”保存关卡进度和资源。重新进入时从关卡开始。启动器会防止重复启动。

主要菜单、升级、属性、结算和八页帮助已经汉化，少量英文标签仍保留。`BGM Vol.` / `SFX Vol.` 为音乐 / 音效音量，`Range` 为射程。旧广告已关闭；在线排行、内购与在线客服没有适配。关卡数据包含原版 80 关，随进度解锁；后续关卡尚未逐关验证。

如果出现错误，查看 `runtime/launcher.log` 和 `runtime/touchHLE_log.txt`。请保留完整目录，启动器需要同目录内的 `runtime` 和 `game` 文件夹。

验证结果记录在 `verification.md`。兼容层来源与改动见 `runtime/SOURCE.md`。
