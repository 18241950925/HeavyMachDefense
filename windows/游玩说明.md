# Heavy MACH: Defense — Windows 适配版

双击本目录的 `HeavyMachDefense.exe` 启动。全屏启动可以双击 `Fullscreen.cmd`。游玩不需要安装 Python、Java 或 Rust。

启动器会根据屏幕尺寸自动提高内部渲染分辨率。1080p 屏幕通常使用 640×960 的大窗口，或在全屏时以 960×1440 渲染后缩放到屏幕；同时启用 Windows 高 DPI 支持，减少系统缩放导致的模糊。全屏仍保持原版竖屏比例。

需要手动调整时，用记事本打开 `Display.ini`：`Scale=0` 为自动，`Scale=2` 为 640×960，`Scale=3` 为 960×1440，`Scale=4` 为 1280×1920，最高为 6 倍。`Fullscreen=1` 可让双击 EXE 默认全屏。修改后重新启动游戏即可。若出现卡顿，可降低倍数；`Fullscreen-Low.cmd` 可直接使用原始 320×480 渲染。

提高渲染分辨率能减少放大模糊，但部分原版小贴图和预先生成的文字仍受素材分辨率限制。

这是工作区内 iOS 1.0.3 安装包的原版程序，通过修改后的 touchHLE 在 Windows 上运行。游戏图片、音乐、关卡和战斗逻辑来自原安装包。

使用鼠标左键代替触屏点击，按住左键拖动代替滑动。标题画面点击进入，选择 `NEW` 建立存档，在关卡界面选择 `Stage 1` 并点击右下角 `OK`。第一次进入会显示帮助，点击底部 `EXIT HELP MENU` 进入战场。当前新存档自动使用名字 `Player`。

游戏的 Energy Cell 用于生产机甲，Cr 用于购买、研究和升级。选择生产单位、等待完成，然后在战场上指定目标位置。摧毁敌方基地过关；下方的 `MENU`、`BASE UPGRADE` 等按钮仍使用原版界面。

存档保存在 `runtime/touchHLE_sandbox` 内。备份进度时复制这个文件夹；关闭窗口前请点击 `MENU` → `Save & Exit Game` 保存关卡进度和资源。重新进入时从关卡开始。启动器会防止重复启动。

目前使用英文界面，部分字体由兼容层替换。旧广告已关闭；在线排行及应用内购买尚未适配。已实测第一关出兵、战斗与存档重读，后续关卡尚未逐关验证。

如果出现错误，查看 `runtime/launcher.log` 和 `runtime/touchHLE_log.txt`。请保留完整目录，启动器需要同目录内的 `runtime` 和 `game` 文件夹。

验证结果记录在 `verification.md`。兼容层来源与改动见 `runtime/SOURCE.md`。
